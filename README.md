Суть работы

Два прохода: первый необходим для точного подсчета неотрицательных
элементов, чтобы выделить память под новый массив нужного размера. Во
втором проходе происходит непосредственное копирование подходящих
значений, что исключает появление «дырок» в результирующем массиве. Как
и в других задачах с массивами, для корректной работы функции
дополнительно передаются размеры исходного и нового массивов.
